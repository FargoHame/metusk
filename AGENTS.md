## Rules

- Implement the specification phase by phase in order.
- Continue automatically between phases unless genuinely blocked.
- Keep the implementation minimal.
- Do not add optional fields, speculative features, or premature abstractions.
- Preserve unrelated existing changes.
- Use `apply_patch` when editing files.
- Run Ruff and pytest after implementation.
- Do not claim completion unless all checks and CLI verification pass.
- If the AAT draft is ambiguous, choose the smallest reasonable interpretation, isolate it, and document it.
- Report implemented work, test results, ambiguities, and deferred items.
